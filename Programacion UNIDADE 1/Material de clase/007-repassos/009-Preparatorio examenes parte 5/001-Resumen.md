Cuando lleguéis al examen de lenguajes de marcas tendréis
1.-La base de datos ya hecha
2.-Los controladores hechos en python con los endpoint en funcionamiento
3.-y con un HTML y CSS horribles

Qué hacemos en el examen de lenguajes de marcas?
1.-Fase prototipos

a) Creamos prototipos (plantillas pero fuera de Python)
	- doctype
  - html
  - head, body, header, main, footer, etc etc etc
  - Creamos plantillas para
  	- front
    - formulario de insercion
    (más dependiendo del tipo de diseño que hayáis elegido)
  - quiero ver HTML estructurado, marcado, que valide, etc
b) Le ponemos CSS 
	- Primero trabajáis un CSS a mano básico
  - igual que en el resto de examenes vais guardando incrementales paso a paso
  - SOLO cuando hayáis demostrado hacer un estilo básico a mano, usáis IA para mejorarlo
  - Dejando constancia de vuestro estilo y el de la IA
c) Adicionalmente quien quiera usa Javascript/JSON para consumir datos

2.-Fase integración
a) Conectáis los prototipos con python (Jinja, JSON, etc)
Y lo ponéis en marcha todo
