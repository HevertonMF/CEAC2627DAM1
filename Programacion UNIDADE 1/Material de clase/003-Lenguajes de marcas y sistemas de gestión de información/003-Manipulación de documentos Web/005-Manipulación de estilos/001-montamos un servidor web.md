Através do Linux 1.-Temos que estar dentro da máquina virtual 2.-Abrimos o terminal 3.-sudo apt install apache2 4.-A pasta de publicação estará em /var/www/html (onde devemos trabalhar a partir deste momento) 5.-PERO essa pasta não tem permissões 6.-PARa darle permissões, no terminal: 7.-sudo chmod 777 -R /var/www/html 8.-A partir deste momento, seus exercícios deverão estar nessa pasta

9.-Você deve acessar poniendo no navegador http://localhost/[carpeta]

A partir do Windows: 1.-Descarregar e instalaris XAMPP: https://www.apachefriends.org/es/index.html 2.-A pasta de publicação é: C:/xampp/htdocs 3.-A partir deste momento acesse http://localhost/[carpeta]

Caso supuesto: 1.-Primero mova uma pasta de /home/josevicente/prueba1 para /var/www/html/prueba1

2.-Aceda com http://localhos/prueba1
