Proyectos

Buscador de psicólogos

Página principal con todos los profesionales, un buscador por nombre o tema y filtros por especialidad.

Área de pacientes

Registro, inicio de sesión, envío de solicitudes de primera sesión y la página «Mis solicitudes» para ver su estado.

Panel de psicólogos

Cada psicólogo ve las solicitudes que recibe, las marca como contactadas y edita su perfil con foto y especialidades.

Base de datos

Base de datos MySQL con cinco tablas: psicólogos, pacientes, especialidades, psicólogo_especialidad y solicitudes.

Versión web estática

Primera versión del proyecto hecha con HTML, CSS y JavaScript, publicada en GitHub Pages.
