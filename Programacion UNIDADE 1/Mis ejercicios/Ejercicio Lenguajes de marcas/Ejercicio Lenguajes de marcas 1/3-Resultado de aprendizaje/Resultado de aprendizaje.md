Resultado de aprendizaje


**a)** Sí. Son texto plano con etiquetas que describen el contenido, como `<empresa>IVECO</empresa>` en mi currículum.

**b)** Sí. Organizan los datos con significado y permiten procesarlos, buscarlos e intercambiarlos entre programas.

**c)** Sí. Hay lenguajes de presentación (RTF), de procedimiento (LaTeX) y descriptivos (XML). Los más usados son HTML, XML y Markdown.

**d)** Sí. HTML se usa para la web, XML para datos y configuración, SVG para gráficos y RSS para noticias.

**e)** Sí. XML no tiene etiquetas fijas: creo las mías (`<curriculum>`, `<formacion>`) y así sirve para cualquier ámbito.

**f)** Sí. HTML tiene etiquetas predefinidas y tolera errores. XML tiene etiquetas libres y es estricto. Markdown usa símbolos y es muy flexible.

**g)** Sí. Mi XML tiene un prólogo, una raíz única (`<curriculum>`) y elementos anidados en árbol. Toda etiqueta se cierra y se distinguen mayúsculas y minúsculas.

**h)** Sí. Los tres ficheros están bien formados y se procesan sin error. Aun así, el 002 tenía fallos de contenido (`<Educación>`, fechas repetidas) que corregí. Para detectar esos fallos hay que validar con un DTD o un XSD.

**i)** Sí. Los espacios de nombres evitan conflictos entre etiquetas iguales de distintos vocabularios, por ejemplo `cv:nombre` y `emp:nombre`.
