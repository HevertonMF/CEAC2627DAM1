```markdown
Resultado de aprendizaje


**a)** Sí. Son texto plano con etiquetas que describen el contenido, como `<empresa>IVECO</empresa>` en mi currículum.

**b)** Sí. Organizan los datos con significado y permiten procesarlos, buscarlos e intercambiarlos entre programas.

**c)** Sí. Hay lenguajes de presentación (RTF), de procedimiento (LaTeX) y descriptivos (XML). Los más usados son HTML, XML y Markdown.

**d)** Sí. HTML se usa para la web, XML para datos y configuración, SVG para gráficos y RSS para noticias.
```
