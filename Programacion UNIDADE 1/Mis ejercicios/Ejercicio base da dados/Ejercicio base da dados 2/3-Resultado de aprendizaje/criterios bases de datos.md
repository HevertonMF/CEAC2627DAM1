# Criterios de evaluación: Base de datos de ciclistas

**a) ¿Se ha analizado el formato de almacenamiento de la información?**

Sí. Los datos de los ciclistas se guardan en tablas, como en un Excel. Cada ciclista es una fila.

**b) ¿Se han creado las tablas y las relaciones entre ellas?**

Sí, en parte. Creé tres tablas: ciclistas, día que practicó y meta de kilómetros. Intenté conectarlas entre sí, pero la conexión no quedó del todo terminada.

**c) ¿Se han seleccionado los tipos de datos adecuados?**

Sí. Usé texto para los nombres, el email y el teléfono, números para los kilómetros y fechas para los días.

**d) ¿Se han definido los campos clave en las tablas?**

Sí. Cada tabla tiene un número de identificación que no se repite. Sirve para reconocer cada fila.

**e) ¿Se han implantado las restricciones reflejadas en el diseño lógico?**

Sí, en parte. Puse una regla para que el email tenga un formato correcto, y los números de identificación no se repiten.

**f) ¿Se han creado vistas?**

Sí, en parte. Hice una consulta que junta los datos de las tres tablas para verlos todos juntos.

**g) ¿Se han creado los usuarios y se les han asignado privilegios?**

Sí. Creé un usuario y le di permiso para usar las bases de datos.

**h) ¿Se han utilizado asistentes, herramientas gráficas y los lenguajes de definición y control de datos?**

Sí, en parte. Trabajé con comandos escritos en la terminal de MySQL. Unos comandos sirvieron para crear las tablas y otros para crear el usuario y darle permisos.
